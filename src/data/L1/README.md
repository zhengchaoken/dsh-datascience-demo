# L1 描述性分析：把数据讲清楚

> **一句话**：在建模之前，先用统计量与图表回答“规模多大、结构如何、分布长什么样、趋势往哪走”。
> 数据源统一为 `../ecommerce/ecommerce.db`，方法论总览见 [../README.md](../README.md)。

---

## 1. 这层解决什么问题

业务方最常问的三个问题——“卖了多少”“谁在买”“什么时候买”——都属于描述性分析。它不解释原因，也不预测未来，只把事实整理成**可复现、口径一致的数字与图**。

描述性分析做不好，后面所有层都会错：口径混用会让诊断归因失真，分布没看清会让预测模型在长尾上翻车。

## 2. 方法地图

| 主题 | 关键方法 | 在本数据上的落点 |
|---|---|---|
| 集中趋势 | 均值、中位数、众数、加权/几何/调和均值、截尾均值 | 客单价、件单价、客户消费额 |
| 离散程度 | 极差、方差、标准差、MAD、IQR、变异系数 | 订单金额波动、客户消费分化 |
| 分布形态 | 偏度、峰度、分位数、直方图/KDE、ECDF、QQ、箱线图、小提琴图 | 订单金额长尾、年龄分布 |
| 频率与交叉 | 一维频率、累计频率、交叉表、透视表、组内占比与排名 | 省 × 品类、等级 × 渠道 |
| 时序描述 | 日/周/月聚合、滚动统计、环比、累计和、STL、ACF/PACF、断点检测 | 日 GMV 趋势与大促脉冲 |
| 变量关系 | 协方差、Pearson/Spearman、散点、配对图、相关热力图 | 活跃度与消费额 |
| 文本描述 | 分词、词频、bigram、词云、分组对比 | 评价正文语料 |
| 质量检查 | 主键唯一、重复行、空值率、金额链路 | 订单与明细勾稽 |

## 3. 关键成果

**规模与结构。** 九张表合计 16.2 万行，交易主表 `orders` 19,669 行、明细 36,907 行，覆盖 2024-01-01 ~ 2025-06-15 共 532 天。

**金额长尾。** 成交订单金额右偏，中位数约 2,894 元、均值约 6,962 元，均值被少量高客单订单抬高。报数时同时给均值与分位数，才能避免“平均客单价”误导备货与预算。

**日 GMV 结构。** 序列由三部分叠加：缓慢增长的趋势、7 天周期的周末效应、双 11 与 618 的数量级脉冲。春节窗口出现明显低谷。这一结构直接决定 L3 的建模方式。

**交叉与地理。** 省 × 品类热力图显示品类偏好在区域间分布不均；客户数量以广东、浙江、江苏居前。性别与会员等级的卡方检验 p ≥ 0.05，**没有显著关联**——这是一个“看起来有差异、统计上站不住”的典型例子。

**文本。** 评价正文经过分词、停用词过滤后，正面词与负面词的分组词频差异清晰，为后续情感分析与多模态融合提供语料基础。

## 5. 方法提醒

1. **均值不是万能**：长尾分布下中位数更能代表“典型订单”。
2. **卡方显著 ≠ 关系强**：大样本下微小差异也会显著，要同时看效应量（Cramér's V）。
3. **交叉维度不要贪多**：三维以上透视表会迅速稀疏，应转为分组 Top-N 或交给 L2 建模。
4. **文本词频要归一化**：分组对比时按组内总量归一，避免大组天然占优。
