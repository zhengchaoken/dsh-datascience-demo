# 数据科学分析框架

> 这是一份**方法论手册**：讲清数据科学的五个分析层次、每层解决什么问题、用什么方法、产出什么。
> 所有示例都基于同一套电商数据；需要动手时看 [run.md](run.md)，需要看数据本身看 [ecommerce/README.md](ecommerce/README.md)。

---

## 1. 五层框架

数据科学不是“跑几个模型”，而是从**看见现象**到**自主进化**的一条认知链。五个层次逐层递进，每一层都回答一个不同的问题。

| 层次 | 名称 | 核心问题 | 输入 | 主要方法 | 产出 | 评价方式 |
|---|---|---|---|---|---|---|
| L1 | 描述性 Descriptive | 发生了什么？ | 原始明细 | 统计量、分布、交叉表、时序描述、文本词频 | 指标、图表、事实结论 | 口径正确、可复现 |
| L2 | 诊断性 Diagnostic | 为什么会这样？ | L1 的指标与维度 | 相关性、因果推断、异常检测、聚类、序列模式 | 原因假设与证据 | 证据强度、可解释性 |
| L3 | 预测性 Predictive | 接下来会怎样？ | 历史序列与特征 | 回归、分类、时序模型、集成学习、可解释性 | 预测值与区间 | 误差、稳定性、泛化 |
| L4 | 规范性 Prescriptive | 应该怎么做？ | L3 的预测 + 业务约束 | 推荐、策略优化、强化学习、多目标权衡 | 决策建议 | 收益、约束满足、风险 |
| L5 | 认知性 Cognitive | 系统能否自主进化？ | 持续到达的数据与反馈 | 持续学习、元学习、多模态融合、漂移检测 | 自适应系统 | 遗忘率、适应速度 |

### 1.1 为什么要分层

- **L1 决定可信度**：口径错了，后面所有结论都是精确的错误。
- **L2 决定方向**：没有原因分析，预测模型只是在拟合噪声。
- **L3 决定提前量**：预测把“事后解释”变成“事前准备”。
- **L4 决定价值**：预测本身不产生收益，决策才产生收益。
- **L5 决定寿命**：世界会变，一次性训练的系统会随时间失效。

层次之间不是硬隔离：同一份数据可以被不同层次反复解读——描述性看分布，诊断性看原因，预测性看趋势，规范性看策略，认知性看系统如何随环境更新。

|---|---|---|

## 2. 横向前置：数据探查

在进入任何一层之前，先回答“这份数据能不能用”。探查不是一次性动作，而是每层开始前的例行体检。

| 探查维度 | 要回答的问题 | 典型产出 |
|---|---|---|
| 结构 | 有哪些表、多少行、主键是什么、表怎么关联 | 数据字典、ER 关系 |
| 完整性 | 哪些字段缺失、缺失是否有业务含义 | 缺失率矩阵、缺失机制判断 |
| 一致性 | 外键是否完整、金额是否勾稽、时间链是否成立 | 一致性检查清单 |
| 分布 | 数值是否长尾、分类是否失衡、时间是否连续 | 分布图、异常值清单 |
| 就绪度 | 能否直接建模、需要哪些清洗与特征工程 | 建模就绪度结论 |

电商数据集的完整探查结果见 [profiling/README.md](profiling/README.md)；探查脚本为 `profiling/data_profiling_report.py`，可对任意 SQLite 库复跑。

## 3. L1 描述性分析

**目标：** 把数据变成可信的事实。不解释原因，只回答“规模、结构、分布、趋势”。

### 3.1 方法体系

| 类别 | 关键概念 |
|---|---|
| 集中趋势 | 均值、中位数、众数、加权均值、几何/调和均值、截尾均值 |
| 离散程度 | 极差、方差、标准差、平均绝对偏差、IQR、变异系数 |
| 分布形态 | 偏度、峰度、分位数、直方图/KDE、ECDF、QQ 图、箱线图、小提琴图 |
| 频率与交叉 | 一维频率、累计频率、交叉表、透视表、组内占比与排名 |
| 时序描述 | 日/周/月聚合、滚动统计、环比、累计和、STL 分解、ACF/PACF、结构断点 |
| 变量关系 | 协方差、Pearson/Spearman 相关、散点图、配对图、相关热力图 |
| 文本描述 | 分词、词频、二元词组、词云、分组对比 |
| 数据质量 | 主键唯一性、重复行、空值率、金额链路一致性 |

### 3.2 电商示例

- `orders` 的实付金额长尾分布：少数高客单订单贡献显著 GMV，报表应同时给均值与分位数。
- `customers × orders` 交叉：省 × 品类、会员等级 × 渠道的结构差异。
- `reviews` 文本：评分与正文词频之间的对应关系。
- 日 GMV 时序：增长趋势 + 周末周期 + 双 11/618 脉冲。

深入阅读：[L1/README.md](L1/README.md)（含主报告、交叉、地理、文本四份专题）。

## 4. L2 诊断性分析

**目标：** 从“是什么”走到“为什么”。L2 的结论必须带证据强度，不能只给相关性。

### 4.1 方法体系

| 方法 | 适用问题 | 关键注意点 |
|---|---|---|
| 相关分析 | 两个变量是否同向变化 | 相关不等于因果；线性相关看不出非线性 |
| 关联规则 | 买了 A 的人是否也买 B | 支持度、置信度、提升度三者要同时看 |
| 聚类 | 客户/商品能否分成有意义的群 | 标准化、K 的选择、业务可解释性 |
| 异常检测 | 哪些记录偏离常态 | 区分“数据错误”与“业务异常” |
| 因果推断 | 某个动作是否真的带来效果 | 选择偏差、混淆变量、倾向得分、平衡性检验 |
| Granger 因果 | 一个序列是否领先于另一个序列 | 只说明预测性领先，不等于机制因果 |
| 序列模式 | 用户行为是否有稳定先后顺序 | 最小支持度决定模式数量 |

### 4.2 电商示例

- 优惠券是否真的提升了客单：倾向得分匹配 + 协变量平衡，而不是简单对比用券/不用券。
- 异常订单：批发型大单（件数极大）与价格异常（单价约为常态 10 倍）是可解释的业务异常，不应直接剔除。
- RFM 聚类：最近购买、频次、金额三维分群，给出可运营的客户画像。
- 购买序列：品类之间的转移概率与频繁序列，支撑关联推荐。

深入阅读：[L2/README.md](L2/README.md)（诊断主报告、因果、Granger、异常、聚类、序列六份专题）。

## 5. L3 预测性分析

**目标：** 用历史规律估计未来。预测的价值不在“算得准”，而在“误差可控、区间可信、峰值可解释”。

### 5.1 方法体系

| 方法 | 用途 | 关键注意点 |
|---|---|---|
| 统计时序 | ARIMA / SARIMA | 平稳性、定阶、季节性 |
| 深度学习时序 | LSTM / GRU / Seq2Seq | 窗口构造、归一化、大促尖峰 |
| 集成学习 | XGBoost / LightGBM | 特征工程、交叉验证、类别不平衡 |
| 分位数预测 | 预测区间 | 覆盖率检验，而不是只看点预测 |
| 多步预测 | 未来 N 天 | 误差随步长累积 |
| 可解释性 | SHAP | 全局重要性与单样本归因 |
| 迁移学习 | 跨品类/跨场景 | 源域与目标域分布差异 |

### 5.2 电商示例

- 日 GMV 预测：log1p 压缩大促尖峰，滚动一步预测，比较 ARIMA/SARIMA/LSTM/GRU。
- 大促峰值识别：把“是否高 GMV 日”作为分类任务，用集成模型给出概率。
- 分位数区间：给出 P10/P50/P90，支撑备货与预算的上下界。
- SHAP：解释哪些行为特征在推动复购或高客单。

深入阅读：[L3/README.md](L3/README.md)（预测主报告、集成、多步、分位数、迁移、SHAP 六份专题）。

## 6. L4 规范性分析

**目标：** 从“会预测”走到“会决策”。L4 要在收益、成本、风险、体验之间做取舍。

### 6.1 方法体系

| 方法 | 决策场景 | 关键注意点 |
|---|---|---|
| 协同过滤 | 推荐什么商品 | 冷启动、稀疏性、隐式反馈 |
| 矩阵分解 | 补全用户-商品偏好 | 隐式评分与显式评分的差异 |
| 序列推荐 | 下一个买什么 | 时序顺序、重复购买 |
| 上下文赌博机 | 发什么券、给什么价 | 探索与利用的平衡 |
| 强化学习 | 库存、定价、长期收益 | 状态/动作/奖励设计、离线评估 |
| 多目标优化 | GMV 与毛利、库存与体验 | 帕累托前沿而非单点最优 |
| 因果推荐 | 去掉曝光偏差 | IPS 权重、方差与稳定性 |

### 6.2 电商示例

- 用订单明细构造用户-商品隐式评分，比较 UserCF / ItemCF / SVD / 序列推荐。
- 优惠券发放作为上下文赌博机问题，比较 ε-贪心、UCB、Thompson 采样的累积遗憾。
- 库存补货作为 MDP，用 DQN 学习长期补货策略。
- GMV 与毛利率的双目标，输出帕累托前沿供业务选择。

深入阅读：[L4/README.md](L4/README.md)（规范性主报告、DQN、赌博机、多目标、因果推荐五份专题）。

## 7. L5 认知性分析

**目标：** 让系统在变化的环境中持续可用。L5 关注的不只是模型精度，还有记忆、适应与融合。

### 7.1 方法体系

| 方法 | 解决的问题 | 关键指标 |
|---|---|---|
| 持续学习 | 新数据到来时如何不忘旧知识 | 首月遗忘率、历史平均误差 |
| 经验回放 | 用旧样本缓冲抑制遗忘 | 缓冲成本、混训比例 |
| 元学习 | 用少量样本快速适应新任务 | 少样本适应后的误差 |
| 多模态融合 | 文本、行为、表格信息如何合并 | 融合增益、鲁棒性 |
| 漂移检测 | 分布什么时候变了 | 检测延迟、误报率 |

### 7.2 电商示例

- 持续学习：日 GMV 按月增量到达，比较 Naive 微调、EWC、经验回放的遗忘曲线。
- 元学习：跨品类少样本快速适应（Reptile）。
- 多模态：评价文本 + 用户行为 + 订单表格三路融合，预测复购。

说明：真实大模型 API 接入与教育领域知识追踪不适用于本电商数据，已在各专题中标注为说明性跳过。

深入阅读：[L5/README.md](L5/README.md)（持续学习、元学习、多模态三份专题）。

## 12. 常见误区

1. **跳过 L1 直接建模**：口径与分布没搞清楚，模型只是在放大错误。
2. **把相关当因果**：看到两个指标同涨就归因，是最常见的误判。
3. **只看点预测**：没有区间与误差分析，预测无法支撑决策。
4. **只优化单一目标**：忽略成本、库存与体验，策略会在别处失衡。
5. **一次性训练**：不做漂移检测与持续更新，模型上线即开始衰减。
6. **把业务异常当脏数据**：批发大单、价格异常是真实业务，先解释再处理。
